# Project Summary dan Milestone

## Ringkasan

Proyek ini membuat chatbot AI bernama **SAPI** yang berjalan melalui Hermes Agent dan dapat diakses dari Telegram. Fokus proyek adalah integrasi, kemudahan instalasi, dokumentasi, dan pengujian percakapan.

| Collaborator | Implementasi atau perbaikan fitur, pengujian, review dokumentasi |

> Ganti `Collaborator` dengan nama asli anggota kedua.

## Milestone

### Milestone 1 — Analisis dan desain
- Menentukan tujuan dan batasan chatbot.
- Menentukan provider/model AI.
- Membuat arsitektur sistem.
- Menetapkan pembagian tugas.

### Milestone 2 — Setup lingkungan
- Memasang requirement.
- Memasang dan menjalankan Hermes Agent.
- Menyiapkan provider/router.
- Membuat bot Telegram.

### Milestone 3 — Integrasi
- Menghubungkan Hermes dengan provider/model.
- Menghubungkan Hermes dengan Telegram.
- Menguji pesan masuk dan balasan.
- Menangani error dasar.

### Milestone 4 — Pengujian dan dokumentasi
- Menguji skenario percakapan.
- Menguji konfigurasi dari instalasi bersih.
- Melengkapi troubleshooting.
- Review repository oleh kedua anggota.

### Milestone 5 — Finalisasi
- Merapikan README.
- Memastikan secret tidak masuk Git.
- Membuat demo.
- Menyiapkan presentasi dan laporan.

## Kriteria Selesai

- Chatbot dapat dijalankan dari lingkungan baru mengikuti README.
- Bot dapat menerima dan membalas pesan Telegram.
- Provider/model berhasil dikonfigurasi.
- Dokumentasi menjelaskan requirement, instalasi, penggunaan, dan troubleshooting.
- Tidak ada token atau API key di repository.
